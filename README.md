# AcademiaDoZe

Projeto acadêmico de gestão da Academia do Zé.

A atividade 09 inclui uma interface .NET MAUI para Dashboard e CRUD de Logradouro.

A atividade 10 implementa configurações de tema e banco, além de identidade visual. Consulte [README_ATIVIDADE_10.md](README_ATIVIDADE_10.md) para executar, validar e preparar a entrega.
